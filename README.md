# golf-record-app

라운딩 중 홀별 기록을 입력하는 아이폰용 웹앱(PWA). 서버 없음, 데이터는 폰(localStorage)에만 저장.

## 배포 (GitHub Pages)
1. 이 폴더를 GitHub 저장소로 올리고 Settings → Pages → main 브랜치 / root 선택
2. 아이폰 Safari에서 주소 열기 → 공유 → **홈 화면에 추가**
3. 한 번 열어두면 이후 오프라인(신호 없는 코스)에서도 동작

## 사용
새 라운드 → 골프장·동반자·캐디·홀별 파 입력 → 홀마다 탭 입력(스코어까지 누르면 다음 홀로 자동 이동)
→ 종료/요약 → **내보내기** → 공유 시트에서 AirDrop → Mac

SCM(파 세이브)은 GIR 실패 + 파 이하 스코어이면 자동 판정. 드라이버 'X'는 OB·해저드 등 생존 실패.
